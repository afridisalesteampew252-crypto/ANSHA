## Tables

| Table | Purpose |
|---|---|
| `bank_account_sequences` | FY counters for `BNK-YYYY-NNNN` |
| `bank_transaction_sequences` | FY counters for `BTXN-YYYY-NNNN` |
| `bank_accounts` | Master: name, bank_name, currency, iban/account_number, opening_balance(+date), is_active, notes |
| `bank_transactions` | Ledger lines: txn_date, amount (>0), direction `in\|out`, description, reference, reconcile flags, optional links |

RLS: ops-only via `private.is_ops_user()` on both data tables. Sequence tables deny direct access.

### `bank_accounts` columns

- `account_code` unique (`BNK-…`)
- `name`, `bank_name`, `currency` (3-letter)
- `iban` and/or `account_number` (at least one required)
- `opening_balance` numeric(14,2) default 0
- `opening_balance_date` date nullable
- `is_active` boolean default true
- `notes`, `created_by`, `created_at`, `updated_at`

### `bank_transactions` columns

- `txn_number` unique (`BTXN-…`)
- `bank_account_id` → `bank_accounts` ON DELETE RESTRICT
- `txn_date`, `amount` (>0), `direction` (`in`|`out`)
- `description`, `reference`
- `is_reconciled`, `reconciled_at`, `reconciled_by`
- Optional links (nullable):
  - `remittance_id` → `remittances` ON DELETE SET NULL
  - `supplier_payment_id` → `supplier_payments` ON DELETE SET NULL
  - `expense_id` uuid (soft; Phase 35 adds FK when `expenses` exists)

## Ledger balance

```text
balance := opening_balance
         + SUM(amount WHERE direction = 'in')
         - SUM(amount WHERE direction = 'out')
```

Helper: `private.bank_account_ledger_balance(uuid)`  
Public: `get_bank_account_balance(p_account_id uuid) RETURNS numeric`
