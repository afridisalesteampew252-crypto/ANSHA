# Phase 37 — Payroll / leave / EOS MVP

## Scope
Ops-only HR-lite (not full HRIS). Additive migration `20260918260000_phase_37_payroll.sql`.

## Tables
- `employees` — optional `admin_profile_id`, name, join_date, basic_salary, currency, status (`active|inactive|terminated`), optional soft `bank_account_id` (no FK)
- `leave_requests` — employee, leave_type (`annual|sick|unpaid|other`), dates, status (`pending|approved|rejected`)
- `payroll_runs` — PR-YYYY-NNNN, period, currency, totals, status (`draft|posted|cancelled`), optional soft `bank_account_id`
- `payroll_lines` — basic / allowances / deductions / net per employee (unique per run)

## RPCs
- `decide_leave_request`
- `create_payroll_run` — seeds lines from active employees matching currency
- `update_payroll_line`
- `post_payroll_run` / `cancel_payroll_run` — no bank auto-pay
- `estimate_employee_eos` — `basic_salary * (days/365.25)`; returns disclaimer (not legal advice)

## UI
`/admin/payroll` tabs: Employees, Leave, Payroll runs, EOS estimate. Nav under Team.

## Guards
- All RLS / RPCs use `private.is_ops_user()`
- Migration ends with overload-count guard: exactly one `private.is_workspace_user(check_user_id uuid)`
- No zero-arg `is_workspace_user()` created
