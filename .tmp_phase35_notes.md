# Phase 35 — Expenses notes for GL agent (Phase 38)

## What Phase 35 posts

Operating expenses only (rent, utilities, office, travel, marketing, professional fees, insurance, maintenance, bank charges, other). **Not payroll** (Phase 37). **Not inventory landed cost** (Phase 33).

Numbers: `OPEX-YYYY-####` (distinct from export `EXP-`).

## Suggested GL mapping on post

When an expense moves `draft → posted`, create a journal entry:

| Debit | Credit |
|---|---|
| Expense P&L account from `expense_categories.gl_account_hint` (or category code map) | Cash / Bank / Clearing by `payment_method` |

Seeded `gl_account_hint` values (soft hints, not live COA codes yet):

| code | hint |
|---|---|
| rent | 6100 Rent expense |
| utilities | 6200 Utilities |
| office | 6300 Office supplies |
| travel | 6400 Travel |
| marketing | 6500 Marketing |
| professional | 6600 Professional fees |
| insurance | 6700 Insurance |
| maintenance | 6800 Maintenance |
| bank_charges | 6900 Bank charges |
| other | 6999 Other operating expense |

### Credit side by payment method

- `bank_transfer` / `cheque` / `card` → Bank asset (`expenses.bank_account_id` when set; else default operating bank)
- `cash` → Cash on hand
- `remittance_company` / `other` → Clearing / suspense until reconciled

## Cancel

`cancel_expense` sets status `cancelled` only. If a GL journal was written on post, reverse it on cancel (or block cancel after period close).

## Bank link

`expenses.bank_account_id` is optional. FK to `bank_accounts` is added only when that table exists. On post, Phase 34 may also want an outbound `bank_transactions` row; coordinate so GL and bank ledger stay consistent (one source of truth for cash movement).

## RPCs to hook

- `public.create_expense(..., p_post boolean)` — may create+post in one call
- `public.post_expense(p_expense_id)`
- `public.cancel_expense(p_expense_id)`
- `public.update_expense(...)` — draft only; no GL yet

Do not double-post if create already posted.
