# Phase 39 — Outbound email MVP (notes)

Applied to live project `ydrnilquojvalhgifest`.

## Migration

`supabase/migrations/20260918280000_phase_39_outbound_email.sql`

Ops-only via `private.is_ops_user()`. Does **not** recreate `private.is_workspace_user()`.

## Table

| Table | Purpose |
|---|---|
| `outbound_email_log` | Append-only send log: `to_email`, `subject`, `body_preview`, `status` (`sent`\|`failed`), `provider`, `provider_message_id`, `error_message`, optional `related_invoice_id`, `created_by`, `created_at` |

RLS: ops SELECT + INSERT (`created_by = auth.uid()`). No UPDATE/DELETE.

## Edge Function

`send-outbound-email` — JWT required; active `admin|staff` only. Uses caller JWT to insert the log (no service role). Resend HTTP API for delivery.

## Admin UI

`/admin/email` — compose + recent log. Optional “email invoice link” stub looks up invoice by number and fills verification URL. Nav under Inbox (ops only; sales nav unchanged).

## Env / secrets (required for real sends)

Set on **Supabase Edge Function secrets** (project `ydrnilquojvalhgifest`), not as `NEXT_PUBLIC_*` and not in the Next.js public bundle:

| Variable | Where | Required |
|---|---|---|
| `RESEND_API_KEY` | Edge secrets | **Yes** — without it the function returns HTTP 503 |
| `RESEND_FROM_EMAIL` | Edge secrets | No — default `ANSHA Trading <noreply@anshatradingco.com>` |

CLI example:

```bash
supabase secrets set RESEND_API_KEY=re_xxx RESEND_FROM_EMAIL="ANSHA Trading <noreply@anshatradingco.com>" --project-ref ydrnilquojvalhgifest
```

Also ensure Resend domain/sender is verified. SMTP not implemented in this MVP.

Vercel: no new public env vars required for this slice. Documented in `docs/Deployment.md`.
