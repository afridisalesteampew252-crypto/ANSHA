## Tables

| Table | Purpose |
|---|---|
| `gl_journal_sequences` | FY counters for `JE-YYYY-NNNN` |
| `gl_accounts` | Chart: code, name, type `asset\|liability\|equity\|revenue\|expense`, is_active |
| `gl_journals` | Header: draft/posted/reversed, entry_date, totals, optional `source_module`/`source_id` |
| `gl_journal_lines` | Debit XOR credit lines; balanced on post |

Seeded default chart when empty: Cash 1000, AR 1100, Inventory 1200, AP 2000, VAT Control 2100, Owner Equity 3000, Sales 4000, COGS 5000, Operating Expenses 6000.

## RPCs

- `upsert_gl_account(...)`
- `create_gl_journal` / `replace_gl_journal_lines` / `update_gl_journal_header`
- `post_gl_journal` / `reverse_gl_journal` / `delete_draft_gl_journal`
- Reports: `gl_trial_balance(as_of)`, `gl_profit_and_loss(from,to)`, `gl_balance_sheet(as_of)`

## Admin UI

- `/admin/ledger` — accounts + journals (create draft, post, reverse)
- `/admin/reports` — P&L, balance sheet, trial balance tabs

## How other modules should journal (TODO — not auto-posted yet)

|---|---|---|
| Phase 34 bank | Manual in/out (or reconcile) | Debit/credit Cash (1000) vs clearing / AR / AP / expense |
| Phase 35 expense | `post_expense` | Debit expense account from `gl_account_hint` (or 6000), credit Cash/Bank by payment method |
| Phase 35 expense | `cancel_expense` | Reverse the posted journal if one exists |
| Remittance | confirmed | Debit Cash, credit AR |
| Customer invoice | tax/commercial issued | Debit AR, credit Sales (+ VAT Control) |
| Supplier payment | confirmed | Debit AP, credit Cash |
| Landed cost | posted pack | Debit Inventory, credit AP/Cash/clearing |
| Payroll (37) | posted run | Debit expense, credit Cash/payable — deferred |

MVP is manual journals + statement views. Wire auto-posting in a later phase; set `source_module` + `source_id` when doing so to avoid duplicates.
