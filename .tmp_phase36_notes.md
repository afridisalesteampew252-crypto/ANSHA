## Assumptions (also in RPC `assumptions` payload)

| Item | Rule |
|---|---|
| Default rate | 5% (UAE standard) |
| Output docs | `tax_invoice`, `commercial_invoice` |
| Output basis | `invoices.tax_amount`; taxable = `subtotal - discount_amount` |
| Input (customer module) | `purchase_invoice` document type, same status/date rules |
| Input (supplier) | `supplier_invoices` in date range; total treated **gross-inclusive**; rate from linked `purchase_orders.vat_rate` else 5% |
| Excluded docs | `delivery_note`, `quotation`, `proforma_invoice` |
| Excluded statuses | `draft`, `cancelled` |
| FX | None — rollups per currency; UI KPIs focus AED |
| GL | None — reporting pack only |
